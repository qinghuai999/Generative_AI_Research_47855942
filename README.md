# Generative_AI_Research_47855942

Repository for the research project "Using Generative AI Tools - Boon or Bane" (REIT6811, University of Queensland).

## Repository Structure

| Folder | Contents |
|---|---|
| `01_Literature_Review/` | Journal articles, conference papers, books and news articles |
| `02_Quantitative/` | Survey questions, raw and cleaned data, Python analysis scripts, reports |
| `03_Qualitative/` | Interview protocols, de-identified transcripts, consent form templates, visualisations, insights report |
| `04_Drafts_and_Reports/` | Research proposal, conference paper drafts, final report |
| `05_Additional_Materials/` | Participant information sheets, photos and other media |

## Naming Conventions

Files follow the pattern `Description_vXX.ext`. Version numbers are used instead of words like "final" or "latest". Underscores are used instead of spaces so that filenames work correctly in scripts and across operating systems.

## How to Navigate

Start in the folder matching the type of material you need. Raw data is kept separate from cleaned data so the originals are never overwritten. Each analysis script in `02_Quantitative/Scripts/` reads from `Cleaned_Data/`.

## Contributing

1. Fork this repository and clone it to your machine.
2. Create a branch named after the work you are doing, for example `add-interview-transcripts`.
3. Make your changes and commit with a message describing what changed.
4. Open a pull request for review before merging into `main`.

## Data Access Note

All files in this repository are placeholders. Real interview transcripts, consent forms and any identifiable participant data are stored separately in UQ RDM under restricted access and are never committed here.
